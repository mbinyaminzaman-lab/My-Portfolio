# Muhammad Binyamin Zaman — Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive visual design
- `script.js` — mobile navigation behavior
- `assets/Muhammad_Binyamin_Zaman_CV.pdf` — CV used by the Download CV button

## Run locally
Open `index.html` in a browser.

## Publish
You can publish this project with GitHub Pages, Netlify, Vercel, or another static hosting service.

## Profile photo
The portfolio uses the supplied profile photo in the Home and About sections.
